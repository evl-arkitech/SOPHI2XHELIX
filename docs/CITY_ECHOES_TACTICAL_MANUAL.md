## 2. Launching the Simulation

### Option 1: 3D Interactive Tactical Simulator (Default)
Launches the full Three.js / WebGL 3D tactical simulator with dynamic lighting, acoustic occlusion, and live Double Helix HUD overlay:
```bash
python -m doublehelix.cli.main city-echoes-play --level 1
```

### Option 2: Surveillance CCTV Bodycam Matrix
Launches the diegetic CCTV surveillance deck with real-time video feeds, multi-camera switching, and mission dispatch:


